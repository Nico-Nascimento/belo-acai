
# 🍧 Belô Açaí

O **Belô Açaí** é uma aplicação web focada em simular um **sistema de pedidos de açaí**, permitindo ao usuário montar seu pedido escolhendo tamanhos, adicionais, extras e observações personalizadas.

O projeto foi desenvolvido pensando em um fluxo real de compra, com atenção especial à experiência do usuário.

---

## 🚀 Tecnologias utilizadas

- **Next.js** (App Router)
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Shadcn UI**
- **Framer Motion**

---

## ✨ Funcionalidades

- Seleção de tamanho do açaí
- Escolha de adicionais e extras
- Campo de observações personalizadas
- Carrinho de compras
- Cálculo automático de valores
- Interface responsiva
- Animações e feedback visual
